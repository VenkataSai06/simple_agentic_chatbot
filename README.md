# Agentic AI Assistant

A simple agentic AI chatbot built with Flask and Groq. The assistant can understand user requests, decide when to use tools, and return natural-language responses.

## Features

- AI-powered conversational chat
- Session-based chat history
- Safe mathematical calculations
- Current date, time, and day lookup
- Save personal notes to a JSON file
- Retrieve previously saved notes
- Clear chat history
- Simple browser-based interface

## Technologies

- Python
- Flask
- Groq API
- HTML, CSS, and JavaScript
- JSON file storage
